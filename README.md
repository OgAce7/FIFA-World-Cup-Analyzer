# FIFA World Cup Analyzer

A graphical, interactive representation of FIFA World Cup statistics from **1930 to 2026** — a full pipeline from raw match data to a live dashboard, including a leakage-safe win predictor model.

The project is split into four independent stages:

```
data/raw/            → the untouched source dataset
pipeline/preprocess.py  → cleaning, standardization, feature engineering
pipeline/analytics.py   → reusable aggregation functions behind every chart
ml/train_win_predictor.py → logistic regression win predictor
api/app.py            → Flask API serving analytics + ML results as JSON
frontend/index.html   → single-page Chart.js dashboard
```

## What it does

- Cleans and standardizes ~1,069 World Cup matches (1930–2026), fixing known
  data issues (unreliable goal totals, multi-host tournaments, historical/defunct
  national teams like West Germany or the Soviet Union).
- Computes global tournament statistics (goals per tournament, stage breakdowns,
  top teams by wins, host country history, goal margins) and per-country
  statistics (win/draw/loss record, goals for/against, deepest stage reached,
  top opponents).
- Trains a logistic regression model to predict whether a team wins a given
  match, using only pre-match historical data (no leakage), evaluated against
  dummy baselines on a held-out set of the three most recent tournaments
  (2018, 2022, 2026).
- Serves everything through a small Flask API, visualized in a single dark
  themed HTML/JS dashboard (no build step required).

## Setup

Requires Python 3.10+.

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Running the project

Run these in order — each stage depends on the output of the previous one.

**1. Build the processed datasets**

```bash
python pipeline/preprocess.py
```

Reads `data/raw/fifa_world_cup_all_matches_1930_2026.csv` and writes
`matches_clean.csv`, `matches_long.csv`, `team_name_map.csv`, and a run
report into `data/processed/`.

**2. Train the win predictor (optional — a trained model is already committed)**

```bash
python ml/train_win_predictor.py
```

Writes the trained model, evaluation metrics, feature importance, and a
`results.json` consumed by the API into `ml/`.

**3. Start the API**

```bash
python api/app.py
```

Runs on `http://localhost:5000`.

**4. Open the dashboard**

Open `frontend/index.html` directly in a browser (it calls the API at
`localhost:5000` via CORS-enabled requests).

## API reference

| Endpoint | Description |
|---|---|
| `GET /api/countries` | List every valid country/team name |
| `GET /api/years` | List every valid World Cup year |
| `GET /api/global?year=<int>` | Global stats (goals per tournament, stages, result methods, top teams, hosts, goal margins). `year` optional. |
| `GET /api/tournaments/<year>` | Same bundle as `/api/global`, hard-scoped to one tournament |
| `GET /api/countries/<country>?year=<int>` | Per-country record, goals for/against, deepest stage, result methods, top opponents |
| `GET /api/ml/result` | Win predictor metrics, baseline comparison, feature importance |

All errors return structured JSON (`{"error": "..."}`) with an appropriate
HTTP status code, including unmatched routes.

## Model summary

- **Target:** whether a team wins a given match (binary)
- **Model:** Logistic Regression on 10 standardized, pre-match historical features
- **Split:** time-based — trained on tournaments through 2014, tested on 2018/2022/2026
- **Result:** 70.5% accuracy / 0.77 ROC-AUC vs. a 58% majority-class baseline

See `ml/model_summary.md` for the full feature list, limitations, and caveats.
This model is exploratory/explanatory — it is **not** intended as a betting
or forecasting tool.

## Data source

`data/raw/fifa_world_cup_all_matches_1930_2026.csv` — match-level results for
every FIFA World Cup from 1930 through 2026, including host, stage, scores at
halftime/fulltime/extra time/penalties, and result method.
